# Zebra_Identifier

## Dataset

Dataset Downlaod Link (split_data): https://drive.google.com/drive/folders/1i0IqvV2wKIJmbLSr63aRiu8VbCv0ZuS7?usp=sharing

The dataset was generated by me. I manually looked through images and labeled them as:

* `y` = zebra crossing present
* `n` = no zebra crossing

I did not use data generated by anyone else. I did share my labeled data with friends so they could merge it with their own datasets.

The images come from 5 zones:

* Bern
* Chur
* Lugano
* St. Gallen
* Winterthur

Because there were many more negatives than positives, I expanded the positive training data by rotating each image (0°, 90°, 180°, and 270°) and mirroring the results, turning one positive image into eight. This preprocessing was done locally, so the provided dataset already contains these augmented samples.

## Steps to Train the Model

1. Run `augment_data.py` using `augment.sh`.
2. Run `main_sebra_train.py` using `main_sebra_train.sh`.
3. Run `analyze_sebra_model.py` using `analyze_sebra_model.sh`.

## augment_data.py

Creates additional copies of every image in the training split using:

1. **Gaussian Blur** – improves robustness to blurry images.
2. **Grayscale** – reduces dependence on color.
3. **Shadow & Contrast** – improves robustness to different lighting conditions and shadows.
4. **Affine Skew** – helps the model handle different camera angles.

## main_sebra_train.py

Trains the classifier.

* Fine-tunes a pretrained ResNet-18 for 10 epochs.

* Saves the best-performing model.

* Uses class-weighted cross-entropy (`1.0` for `n`, `3.54` for `y`) to compensate for class imbalance.

* Uses the Adam optimizer with an initial learning rate of `0.001`.

* Reduces the learning rate every 3 epochs using a scheduler.

* Applies random horizontal flips, small rotations, and color jitter during training.

* Selects the best model using:

  `score = 0.6 * F1 + 0.4 * Recall`

  to place extra emphasis on detecting zebra crossings.

* Computes an optimized probability threshold after training.

* Saves each run in a timestamped folder inside `runs/` containing:

  * `metrics.json`
  * `checkpoint.pth`
  * `best_model.pth`

## analyze_sebra_model.py

* Automatically loads the latest trained model.
* Evaluates it on the validation set.
* Reports accuracy, precision, recall, F1-score, and the confusion matrix in `runs/.../analysis/report.txt`.
* Generates Grad-CAM visualizations showing which image regions influenced the model's predictions.
